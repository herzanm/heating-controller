# Changelog Rules

When releasing new functionality:

## Added

New features.

Example:

```text
Added OLED status screen
```

---

## Changed

Modified existing behavior.

Example:

```text
Changed relay diagnostics implementation
```

---

## Fixed

Bug fixes.

Example:

```text
Fixed relay feedback detection
```

---

## Removed

Deleted functionality.

Example:

```text
Removed legacy relay driver
```

---

## Security

Security related changes.

Example:

```text
Added web authentication
```
